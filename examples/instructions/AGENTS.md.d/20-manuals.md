This is a sample catalog. These pages are installed by the agent packages.
Read a page with `man lab-reference NAME` when the task needs its details.
The Markdown sources are also in this repository.

- agent: launch a harness with composed instructions and selected roles.
- agent.template: render an instruction template with parameters and facts.
- agent-transcripts: inspect native sessions through a common audit index.

A host can generate this list from its installed manual pages with `apropos`.
